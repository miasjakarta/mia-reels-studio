# Mia Reels Studio — 사용 설명서

## 무엇을 할 수 있나요?
- 주제 입력 후 5개 장면 한국어 대본 작성 (무료 기본 대본 또는 선택적 OpenAI API)
- 대본을 직접 수정하고 사진 0~5장 업로드
- 인터넷 연결을 이용한 한국어 음성(gTTS) 자동 생성
- 자막이 영상에 새겨진 1080×1920 세로 MP4 생성
- 권리가 있는 MP3 배경음악을 선택적으로 추가
- 완성 영상을 미리 보고 MP4 다운로드

**주의:** 기본 대본은 AI가 사실을 조사하지 않습니다. OpenAI API 대본도 가격·주소·정책 등의 사실 확인이 필요합니다. 기본 디자인은 정적 이미지 기반이며 AI가 실제 장면 영상을 만들어 주는 방식은 아닙니다. 음성은 무료 온라인 gTTS에 의존하며 서비스 상황에 따라 실패할 수 있습니다. 음성은 gTTS 한국어 기본 음성 한 종류입니다. 여성/남성 선택 기능은 아직 없습니다.

## 시작하기 (Windows 10/11, Mac)

1. Python 3.10 이상을 설치하세요. Windows 설치 시 **Add Python to PATH** 체크.
2. ZIP 파일을 압축 해제하고 `mia_reels_studio` 폴더를 여세요.
3. 해당 폴더에서 터미널(Windows: 주소창에 `cmd` 입력)을 열고 아래를 순서대로 실행하세요.

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Mac에서 `python`이 없으면 `python3`를 사용하세요.
4. 브라우저에서 자동으로 열리는 `http://localhost:8501`을 사용하세요.
5. 주제 입력 → **5개 장면 대본 만들기** → 대본 검토/수정 → **MP4 자동 생성** → 다운로드.

## 아이패드에서 사용하려면
웹앱은 컴퓨터에서 실행됩니다. 아이패드에서 접속하려면 컴퓨터와 아이패드가 같은 Wi-Fi에 있고, 컴퓨터 방화벽과 네트워크 설정에서 접근이 허용되어야 합니다. 컴퓨터의 로컬 IP 주소를 사용해 `http://컴퓨터IP:8501`에 접속합니다. 외부 인터넷에 공개하지 마세요. 원한다면 추후 클라우드 배포가 가능합니다(별도 설정/비용 가능).

## 비용과 보안
- 무료 기본 대본, 사진 합성, MP4 출력은 유료 API 키가 필요 없습니다.
- gTTS 음성은 인터넷을 사용하며 텍스트가 외부 서비스로 전송됩니다.
- OpenAI API 옵션을 사용하면 별도 과금됩니다. ChatGPT 구독과 별개입니다.
- OpenAI API 키는 앱의 비밀번호 입력 칸에 입력하세요. 소스 코드에 직접 적지 마세요.
- MP3 음악은 사용 권한을 가진 파일만 사용하세요.

## 알려진 제한
- 대본 길이에 따라 총 영상 길이는 약 20~40초 이상이 될 수 있습니다.
- 자막은 장면별로 고정 표시됩니다. 단어별 하이라이트/자동 음성 인식 자막은 아직 지원하지 않습니다.
- 무료 대본은 주제 기반 일반 문구를 생성합니다. 특정 앱 3개의 실제 이름이나 정확한 정보를 자동 조사하지 않습니다.
- 영상 합성에는 시간이 걸립니다. 저사양 컴퓨터는 더 느릴 수 있습니다.
- 완성된 영상을 인스타그램에 자동 게시하지는 않습니다.
